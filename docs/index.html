Get Hired

Interview questions, answered properly.

Bias is error from wrong assumptions (model too simple → underfitting); variance is error from sensitivity to data fluctuations (model too complex → overfitting). Total error = bias² + variance + irreducible noise. Reduce bias with a more expressive model or better features; reduce variance with regularization, more data, or ensembles. The craft is finding the sweet spot between the two.
Use RAG for knowledge: private or fast-changing information, citations, and reduced hallucination — you retrieve relevant documents at inference time and pass them as context. Use fine-tuning for behavior: consistent output format, domain style, or making a small model punch above its weight. Rule of thumb: try prompting first, RAG if the model lacks knowledge, fine-tune only if you need to change how it behaves.
LoRA freezes the pretrained weights W and learns a low-rank update ΔW = BA, where B and A are small matrices with rank r ≪ min(d,k). You train ~0.1% of the parameters, and at inference you can merge W + BA for zero overhead. It works because the weight updates needed to adapt a pretrained model have low intrinsic rank — the model doesn't need to change in many directions to learn a new task.
scores = Q @ K.transpose(-2,-1) / sqrt(d_k) → apply mask (fill with −1e9 where masked) → weights = softmax(scores, dim=-1) → output = weights @ V. The √d_k scaling stops dot products from growing with dimension, which would push softmax into regions with vanishing gradients. The full PyTorch solution lives in the repo's interview-prep folder.
