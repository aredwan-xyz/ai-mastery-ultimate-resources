<details>
<summary><b>🔧 Fine-Tuning Guide (2025)</b></summary>

```
Full Fine-Tuning → Expensive, only if you have 8+ A100s
LoRA / QLoRA   → The sweet spot. 1-2 GPUs, great results
DoRA           → Better than LoRA on most benchmarks
GaLore         → Memory-efficient full-rank training
ORPO           → Alignment without a reference model
DPO            → Direct Preference Optimization (beats RLHF for most uses)
```

**Best Tools:**
- [Unsloth](https://github.com/unslothai/unsloth) — 2–5x faster fine-tuning, 70% less memory
- [Axolotl](https://github.com/OpenAccess-AI-Collective/axolotl) — Production-grade fine-tuning
- [LLaMA Factory](https://github.com/hiyouga/LLaMA-Factory) — UI + CLI, supports 100+ models
- [TRL (Hugging Face)](https://github.com/huggingface/trl) — Official transformers RL library

**Step-by-step:** [Fine-Tuning Walkthrough](resources/llms/fine-tuning-guide.md)

<details>
<summary><b>🕵️ Complete Agents Resource Guide</b></summary>

#### What Are AI Agents?
Agents are LLMs that can **perceive → plan → act → reflect** in a loop, using tools to accomplish goals autonomously.

```
Agent Loop:
  Observe Environment
       ↓
  Think / Plan (LLM)
       ↓
  Use Tools (search, code, APIs, files)
       ↓
  Reflect on results
       ↓
  Repeat until goal is met
```

#### Core Techniques
```
Zero-Shot           → Ask without examples
Few-Shot            → Provide examples in the prompt
Chain-of-Thought    → "Let's think step by step"
Tree-of-Thought     → Explore multiple reasoning paths
ReAct               → Reason + Act in interleaved steps

Generated Knowledge → Generate facts, then use them
```
