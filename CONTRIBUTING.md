# 🤝 Contributing to AI Magic Mastery

Thank you for helping make this the **best AI resource on the internet**! Every contribution, big or small, makes a difference.

---

## 🌟 How to Contribute

### 1. Fork & Clone
```bash
git clone https://github.com/YOUR-USERNAME/ai-magic-mastery.git
cd ai-magic-mastery
git checkout -b feature/add-your-resource
```

### 2. Make Your Changes
Follow the guidelines below.

### 3. Submit a Pull Request
```bash
git add .
git commit -m "feat: add [resource/topic/fix] - short description"
git push origin feature/add-your-resource
```
Then open a PR on GitHub with the title: `[CATEGORY] Brief description`

---

## ✅ What We Accept

| Type | Examples |
|------|---------|
| 📚 New resources | High-quality courses, tutorials, papers, books |
| 📝 Cheatsheets | Quick-reference guides for tools/frameworks |
| 💡 Project ideas | With description, stack, and learning goals |
| 🎯 Interview questions | With thorough answers |
| 🗺️ Roadmap improvements | Better learning paths, new career tracks |
| 🐛 Fixes | Broken links, typos, outdated info |
| 🌍 Translations | Chinese, Spanish, French, Arabic, etc. |

---

## ❌ What We Don't Accept

- Paid course spam / affiliate links
- Outdated resources (pre-2020, unless historically essential)
- Resources without a clear description of why they're valuable
- AI-generated content that isn't fact-checked
- Off-topic content (must be AI/ML related)

---

## 📐 Style Guide

### Adding a Resource
```markdown
| [Resource Name](url) | Provider | Cost | Why It's Great |
```

### Adding a Cheatsheet
- Use code blocks with syntax highlighting
- Include real, runnable examples
- Keep it to one A4-printable length if possible

### Adding a Project
```markdown
### P#: 🎯 Project Name
**What:** One-sentence description
**Stack:** List of libraries/frameworks
**Dataset:** Link to dataset (if applicable)
**Learn:** 3-4 key skills
```
