# Security Policy

## Reporting a Vulnerability

We take the security of **AI Magic Mastery** seriously — even though this is
primarily an educational resource repository.

If you discover a security issue (for example, a malicious link, compromised
dependency in a code example, or an exposed credential in the content), please
report it responsibly:

- 📧 Email: **security@codebeez.ai**
- Please **do not** open a public issue for security vulnerabilities.

Include as much of the following as you can:

- A description of the issue and where it lives (file path / line)
- Steps to reproduce or a proof of concept
- The potential impact

## What to Expect

| Stage | Timeline |
|-------|----------|
| Acknowledgement of your report | within **48 hours** |
| Initial assessment | within **5 business days** |
| Fix or mitigation for confirmed issues | as fast as reasonably possible |

We'll keep you updated throughout, and we're happy to credit you in the fix
(unless you'd prefer to remain anonymous).

## Scope

Because this repo is a curated collection of learning resources, the most
relevant concerns are:

- Links pointing to malicious or compromised destinations
- Code examples that contain insecure patterns presented as best practice
- Accidentally committed secrets or credentials

Thank you for helping keep the community safe. 🛡️
